2. Organization Profiles
| Dimension               | What Earthbux measures                                |
| ----------------------- | ----------------------------------------------------- |
| Financial transparency  | How completely the organization documents spending    |
| Reporting reliability   | Whether promised reports arrive on time               |
| Outcome verification    | Whether claimed results can be independently verified |
| Budget accuracy         | Actual vs. projected expenditures                     |
| Historical performance  | Results of previously funded projects                 |
| Governance transparency | Disclosure of leadership, conflicts, etc.             |
| Scientific evidence     | Quality of evidence supporting proposed activities    |
| Correction history      | Whether errors are acknowledged and corrected         |
